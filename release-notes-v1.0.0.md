# VideoClip Desktop v1.0.0

Primera versión pública de VideoClip Desktop.

VideoClip Desktop es una aplicación gráfica para Linux que permite descargar videos, crear clips por intervalo de tiempo y extraer audio en MP3 desde una interfaz sencilla.

## Funciones principales

- Descarga de videos completos.
- Creación de clips indicando inicio y final.
- Extracción de audio MP3.
- Selección de calidad.
- Análisis previo del video.
- Miniatura, título, canal y duración.
- Nombres personalizados.
- Carpetas favoritas.
- Historial persistente.
- Apertura directa de archivos y carpetas.
- Barra de progreso y cancelación.
- Notificaciones del sistema.
- Integración opcional con cookies de Brave.
- Tema oscuro.

## Incluido

La distribución Linux incluye:

- yt-dlp
- FFmpeg
- ffprobe
- Python runtime
- PySide6 / Qt

No es necesario instalar Python, yt-dlp o FFmpeg por separado.

## Descargas

### AppImage

`VideoClip-Desktop-1.0.0-x86_64.AppImage`

Versión portable para Linux x86-64.

### Debian / Ubuntu

`VideoClip-Desktop-1.0.0-amd64.deb`

Paquete instalable para Ubuntu, Debian y distribuciones compatibles.
